# VCII Website

Static website for the Vanderbilt Center for Intelligent Imaging (VCII).

## Structure

- `index.html` — home
- `about.html` — about
- `people.html` — people / leadership
- `research.html` — research
- `news.html` — news
- `collaborate.html` — collaborate
- `vcii.css` / `vcii.js` — shared styles / scripts
- `assets/` — images

## Local preview

```
python3 -m http.server
```

then open `http://localhost:8000`.

## Deploy (GitHub Pages)

Settings → Pages → Source: `main` branch, `/ (root)`.
